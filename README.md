# 初中生学习成长工作台

面向初中生（含侄女）的**单文件 HTML 教育 App**，覆盖小学到高中全学科，以 aiexams 公开题库作为免费题源。
直接用浏览器打开 HTML 即可使用，无需服务器；少量前端库经 jsdelivr CDN 加载（需联网）。

## 功能
- 全学科刷题（语文 / 数学 / 英语 / 物理 / 化学 / 生物 / 历史 / 地理 / 政治等）
- 本地进度与错题本（`localStorage`）
- 低头探颈检测器（摄像头姿态检测，提醒坐姿）
- 适配 iPad Safari（针对 Safari 兼容性做过专门修复）

## 使用
直接用浏览器打开 `初中生学习成长工作台.html`。
建议部署到静态托管（CloudStudio / GitHub Pages 等）后通过 iPad Safari 访问。
